# AIML_Projects_and_Labs

My projects and lab submissions for AIML.

## Labs

### 1. Basics of Python

- Python basics, functions, NumPy, Pandas, and Matplotlib.

### 2. Module 1 – Lab 1: Introduction to Machine Learning and Feature Extraction

- Machine learning, feature extraction, classification, regression, and text processing.

### 3. Module 1 – Lab 2: Machine Learning Terms and Metrics

- Machine learning concepts, KNN classification, and accuracy metrics.

### 4. Module 1 – Lab 3: Data Augmentation

- Data augmentation using rotation and shear, combined augmentations, grid search, and MNIST digit recognition using 50 images per digit.

### 5. Module 1 – Lab 4: Transforming Data Using Linear Algebra

- Transforming data using linear algebra, feature scaling,transformation matrices, and improving machine learning accuracy through feature transformations.

### 6. Module 2 – Lab 1: Basic Plots

- Data visualization using Matplotlib and Seaborn to analyze automobile features and prices.

### 7. Module 2 – Lab 2: Principal Components Analysis (PCA)

- Dimensionality reduction, explained variance, and 2D/3D visualization using PCA.

### 8. Module 2 – Lab 3A: Manifold Learning (Isomap)

- Manifold learning using Isomap, S-curve dataset visualization, nearest neighbours, geodesic distances, dimensionality reduction, and comparison of PCA with Isomap.

### 9. Module 2 – Lab 3B: t-Distributed Stochastic Neighbor Embedding (t-SNE)

- Dimensionality reduction and high-dimensional data visualization using t-SNE, MNIST handwritten digit clustering, perplexity tuning, iteration comparisons, and PCA vs t-SNE analysis.

### 10. Module 2 – Lab 4: Text Representation

- Text preprocessing using NLTK, BoW, and TF-IDF.
- KNN classification for reviews and spam datasets.
- Compared accuracy using different KNN parameters.

### 11. Module 3 – Lab 1: Loss Functions and Gradient Descent

- Implemented Batch, Stochastic, and Mini-Batch Gradient Descent.
- Compared batch sizes and learning rates.
- Tested gradient descent methods on the Diabetes dataset.
- Implemented a learning rate schedule for SGD.

### 12. Module 3 – Lab 2: Linear Regression

- Implemented Linear and Polynomial Regression.
- Experimented with different polynomial degrees.
- Studied underfitting and overfitting.
- Applied regression to the California Housing Dataset.

## Tools & Libraries

Python, Google Colab, NumPy, Pandas, Matplotlib, Scikit-learn, Keras, and Scikit-image.
